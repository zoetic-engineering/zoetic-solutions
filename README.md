# Zoetic Solutions

Company website at <https://zoetic.solutions>, published with GitHub Pages.
It introduces our custom software services and our premier product, Zoetic Care.

## Local preview

Run `python3 -m http.server 8080` from this directory, then open
<http://localhost:8080>. The site uses static HTML and CSS with no build step,
runtime JavaScript, third-party fonts, analytics, or form submissions.

## Publishing

Changes go through a pull request to `main`. GitHub Pages publishes the repository
root from `main`. `CNAME` preserves the custom domain. Check the Pages deployment
and the served site after merging; a merged change alone does not prove publication.

Keep business contact links and the Zoetic Care destination current. Do not put
credentials, customer records, or private application source in this repository.
